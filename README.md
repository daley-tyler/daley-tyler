# Hi, I'm Tyler

I have a BSc in Computer Science with a minor in Statistical Methods. I build web applications, machine learning experiments and tools for working with data.

I'm interested in software engineering, applied AI and data analytics. My projects focus on clear interfaces, tested application logic and careful evaluation. I use AI-assisted tools during development and maintenance; each project documents its origins, contributions and validation limits.

## Selected projects

### [University Course Planner](https://github.com/daley-tyler/university-course-planner)

A React and TypeScript frontend with a Java Spring Boot API and PostgreSQL database for course search, requirements and semester planning. This began as a university team project. My portfolio improvements focus on parser correctness, planning behavior, tests and a self-contained local demo.

### [Speech Emotion Recognition](https://github.com/daley-tyler/speech-emotion-recognition)

NumPy implementations of classifiers, preprocessing, PCA and clustering, with regression tests and actor-grouped evaluation on RAVDESS speech. I revisited my coursework to correct numerical issues and compare recording-level splits with unseen-speaker evaluation. The reported experiments use cached features; complete audio regeneration remains unverified.

### [Article Retrieval Chatbot](https://github.com/daley-tyler/article-retrieval-chatbot)

A Python document-search application using MiniLM embeddings and NumPy retrieval. It returns cited extracts and declines weakly supported answers. This grew from my Generative AI coursework and includes regression tests and real-model integration checks. Answers are extractive, without an LLM generation service.

### [Daley Dynamics Website](https://github.com/daley-tyler/daley-dynamics-website)

A Vite and vanilla JavaScript business website with a WebGL background and a Node.js enquiry backend. It includes input validation, SMTP delivery logic and local HTTP integration tests. The source is published; production hosting and real inbox delivery remain unverified, and professional case-study details are withheld.

### [Global Heritage Explorer](https://github.com/daley-tyler/global-heritage-explorer)

An R Shiny application with Leaflet maps and ggplot2 charts for exploring UNESCO World Heritage records alongside selected regional points of interest. It demonstrates geospatial data preparation, interactive visualization and attention to the limits of the underlying data.

### [Isometric Strategy Game](https://github.com/daley-tyler/isometric-strategy-game)

A Godot prototype combining city simulation, resource production and combat. It demonstrates simulation architecture, pathfinding and tested save/load behavior. I developed the design and used Codex for implementation, testing, review and generated artwork. Headless checks support the tested behavior; a complete human-played campaign remains unverified.

## Additional project
