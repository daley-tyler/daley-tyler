I work with Python, Java, SQL, React, Linux, Docker, FastAPI and PostgreSQL. I'm looking for junior software engineering, Python, backend and data roles, primarily in Cincinnati and Chicago.

## Selected projects

### [University Course Planner](https://github.com/daley-tyler/university-course-planner)

A React/TypeScript application with a Java Spring Boot API and PostgreSQL for course search, degree requirements and semester planning. This began as a university team project. My portfolio improvements focus on parser correctness, planning behavior, regression tests and a self-contained demo with invented data.

### [Speech Emotion Recognition](https://github.com/daley-tyler/speech-emotion-recognition)

NumPy implementations of classifiers, preprocessing, PCA and clustering, with numerical regression tests and actor-grouped evaluation on RAVDESS speech. I revisited my coursework to correct numerical issues and compare recording-level splits with unseen-speaker evaluation. The recorded experiments use cached features; a complete raw-audio rebuild remains unverified.

### [Article Retrieval Chatbot](https://github.com/daley-tyler/article-retrieval-chatbot)

A Python document-search application using MiniLM embeddings and NumPy retrieval. It returns cited extracts or refuses unsupported questions, with regression tests and real-model integration checks. It uses extractive answers rather than an LLM generation service.

### [Daley Dynamics Website](https://github.com/daley-tyler/daley-dynamics-website)

A Vite and vanilla JavaScript website with a WebGL background and a Node.js enquiry backend. It includes input validation, SMTP delivery logic and HTTP integration tests. The source is published; production hosting and real inbox delivery remain unverified.

### [Global Heritage Explorer](https://github.com/daley-tyler/global-heritage-explorer)

An R Shiny application with Leaflet maps and ggplot2 charts for exploring UNESCO records alongside selected regional points of interest. It demonstrates geospatial data preparation and interactive visualization, with the dataset's coverage limits documented.

I also maintain an [isometric strategy prototype](https://github.com/daley-tyler/isometric-strategy-game) and the [source-only JARVIS interface](https://github.com/daley-tyler/jarvis-interface). Their repositories explain the project origins, included material and validation limits.
