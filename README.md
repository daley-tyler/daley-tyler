# Hi, I'm Tyler

I have a BSc in Computer Science with a minor in Statistical Methods. I develop applications, analytics tools, AI systems and infrastructure through independent and contract work.

I'm interested in software engineering, applied AI and data analytics. I enjoy working on the parts that make a project useful: clear interfaces, reliable application logic and careful evaluation of data and results.

## Selected projects

### [University Course Planner](https://github.com/daley-tyler/university-course-planner)

A React and TypeScript frontend with a Java Spring Boot API and PostgreSQL database for course search, requirements and semester planning. This began as a university team project. My portfolio improvements focus on parser correctness, planning behavior, tests and a self-contained local demo.

### [Isometric Strategy Game](https://github.com/daley-tyler/isometric-strategy-game)

A Godot prototype combining city simulation, resource production and combat. It demonstrates simulation architecture, pathfinding and validated save/load behavior. I developed the design and used Codex for implementation, testing, review and generated artwork.

### [Global Heritage Explorer](https://github.com/daley-tyler/global-heritage-explorer)

An R Shiny application with Leaflet maps and ggplot2 charts for exploring UNESCO World Heritage records alongside selected regional points of interest. It demonstrates geospatial data preparation, interactive visualization and attention to the limits of the underlying data.

### [JARVIS Interface](https://github.com/daley-tyler/jarvis-interface)

Python source and tests for gesture interaction and a local voice command bridge around a TouchDesigner HUD. It demonstrates hand-tracking integration, command routing and testing with synthetic inputs. This is a source-only release; the TouchDesigner scene and visual assets are excluded.
